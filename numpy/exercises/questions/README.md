# NumPy 入门练习

约定 a 是 np.arange(6)。

## 基础题

1. 把 1、2、3 转为数组并加 2。

2. 构造 2×2 的零矩阵。

3. 生成 3 个 1。

4. 生成两个 7。

5. 生成 1 至 5 的奇数。

6. 将 0 到 1 分成 3 个等距点。

7. 构造 2 阶单位矩阵。

8. 取 0 到 4 的末元素。

9. 截取位置 1 至 3 的元素。

10. 求 2×3 全一矩阵的元素总数。

## 理解题

11. 把 0 到 5 改成 3×2。

12. 将行 [2, 4] 转置成列。

13. 二维矩阵逐列求和。

14. 二维矩阵逐行求平均。

15. 判断 flatten 与原数组是否共享内存。

16. 判断连续数组 reshape 后是否共享内存。

## 实战题

17. 为两件商品分别加 1 和 2 元手续费。

18. 提取六天销量 0 至 5 中超过 2 的记录。

19. 检查种子 42 的四个模拟骰子均落在 1 到 6。

20. 计算销量 [2, 3] 与单价 [10, 20] 的总额。
