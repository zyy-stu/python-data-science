# 综合案例：销售分析

在根目录运行 `python projects/sales-analysis/main.py`。项目读取销售、商品和用户表。先检查条数、重复和缺失，再解析日期和数值。完全重复记录合并，冲突业务键报错，缺失数量的行排除出金额统计。金额以整数分计算，避免浮点舍入。

模拟数据原始 5 行，去除 1 条重复和 1 条缺失记录后剩 3 行。键盘合计 600 元，鼠标 80 元，总额 680 元。U1、U2、U3 分别贡献 240、80、360 元。1 月 320 元，2 月 360 元。

这些数值仅针对本模拟样本，且不含缺失数量的记录。`analyze()` 返回按月和按商品字典，可交给后续可视化模块。
