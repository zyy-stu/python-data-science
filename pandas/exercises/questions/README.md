# Pandas 入门练习

使用仓库教学 CSV。prices 为以 product_id 为索引的 price_cents 列，clean 为销售号去重且无缺失数量的销售记录。

## 基础题

1. 读取用户表行数。

2. 取用户表的地区列名。

3. 提取前两位用户编号。

4. 按标签获取 U2 的地区。

5. 取最后一行的用户编号。

6. 筛选华东用户编号。

7. 只保留用户编号列并检查列名。

8. 删除地区列并检查列数。

9. 添加活动标志列并统计真值数量。

10. 价格索引反转后与原有 Series 相加。

## 理解题

11. 统计原始销售表缺失数量。

12. 删除数量缺失后统计行数。

13. 用 0 填充缺失数量并读取整型列表。

14. 找出重复的销售号。

15. 按销售号去重后统计记录数。

16. 按地区统计用户数。

## 实战题

17. 按商品统计清洗后件数。

18. 左连接订单与用户并检查行数。

19. 标记两件及以上的键盘销售记录。

20. 导出用户表到 CSV 文本再读取地区列。
