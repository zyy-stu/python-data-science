# Python 数据科学教程

Python Learning Roadmap 的中文数据科学专题。从 Python 数据处理逐步掌握清洗、探索性分析、可视化、统计和机器学习。

## 学习路线

[Python 基础](https://github.com/zyy-stu/python-basic) → [NumPy](numpy/README.md) → [Pandas](pandas/README.md) → [Matplotlib](matplotlib/README.md) / [Seaborn](seaborn/README.md) → [数据清洗](data-analysis/data-cleaning/README.md) → [探索性分析](data-analysis/exploratory-analysis/README.md) → [统计分析](data-analysis/statistics/README.md) → [Scikit-learn](scikit-learn/README.md) → [机器学习项目](projects/README.md)。

另见 [SciPy](scipy/README.md)、[数据分析](data-analysis/README.md)、[数据可视化](visualization/README.md)、[模拟数据](datasets/README.md)和[开发路线图](ROADMAP.md)。已发布 NumPy 与 Pandas 入门，以及[销售分析案例](projects/sales-analysis/README.md)。

## 安装与检查

使用 Python 3.11+，在仓库根目录激活虚拟环境并运行：

```bash
python -m pip install -r requirements-dev.txt
python -m ruff check .
python -m pytest
```
